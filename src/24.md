EXPLICACIÓN
-----------

Este ejemplo ya no se puede ejecutar puesto que este sistema, lo primero que hacía era realizar una carga en tiempo real del archivo JSON disponible en la web de AVAMET, que ya no ofrece datos meteorológicos en su servicio WFS. 
Tan sólo se dispone de datos sobre la ubicación de los observatorios.

No obstante, el código es igualmente válido para cualquier otro servicio que ofrezca datos sobre precipitación, temperaturas o cualquier dato de interés meteorológico. Tan sólo es necesario mapear adecuadamente las rutas al JSON así como 
parametrizar las columnas de los atributos.
